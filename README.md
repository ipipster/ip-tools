# ip-tools

Small personal productivity tools, shared as-is. Each tool lives in its own folder under [`tools/`](tools) with its own README.

| Tool | What it does | Platform |
|---|---|---|
| [Meet Ringer](tools/meet-ringer) | Rings Teams-style when someone joins your Google Meet meeting before you do | Chrome / Brave extension |

## Download

Ready-to-use packages are on the [Releases](https://github.com/ipipster/ip-tools/releases) page. Each release is named after the tool and version (for example `meet-ringer-v1.1.1`). Download the zip under **Assets**, then follow the tool's README.

You do not need a GitHub account or git to download.

## Suggesting changes

Found a bug or have an idea? Open an [issue](https://github.com/ipipster/ip-tools/issues). Want to change the code? See [CONTRIBUTING.md](CONTRIBUTING.md). Security problems: see [SECURITY.md](SECURITY.md).
